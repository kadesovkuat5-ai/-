# Казахская (и русская) типографика

## Буквы
Казахская кириллица: Ә ә, Ғ ғ, Қ қ, Ң ң, Ө ө, Ұ ұ, Ү ү, Һ һ, І і. Каждый шрифт обязан содержать **все** эти знаки.
- Перед сборкой проверь тестовой строкой: `Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі — Қазақстан, Өскемен, Шымкент`.
- Если знака нет, браузер подставит другой шрифт — буква «прыгнет». Это брак: меняй шрифт.
- Проверенные шрифты лежат в репозитории в `fonts/` (все знаки есть): Montserrat, Oswald, Inter, Rubik, Noto Serif, Roboto Condensed, Golos Text, Playfair Display, Raleway, Nunito, Comfortaa, Exo 2, Caveat, Lobster — см. `fonts/README.md` и `fonts/preview.png`. **Не подходят** (нет казахских знаков): Unbounded, Manrope, Jost, Russo One. Подключай через `@font-face` из `assets/fonts/` (контракт HyperFrames, п. 9).
- Не путать: казахская «І і» (U+0406/U+0456), а не латинская I; «Һ» — U+04BA.

## Анимация по буквам
- Режь текст на графемы (`Intl.Segmenter` или `Array.from`), а не на байты — иначе ломаются знаки.
- Не раскладывай одну букву на отдельные спаны с разными шрифтами.
- Хвосты и нижние элементы (Қ, Ң, Ұ, Ғ) не должны обрезаться: `line-height` ≥ 1.1 и запас снизу у масок.

## Вёрстка
- Казахские слова длинные: в вертикали 1080 px заголовок — до 12–14 символов в строке на крупном кегле. Переноси по смыслу, не механически.
- Не используй CSS `hyphens: auto` для казахского — словаря переносов нет, ломает слова.
- Кавычки «ёлочки», тире — длинное (—), неразрывный пробел после коротких слов («и», «в», «мен», «да»).
- Кегль на телефоне: основной текст ≥ 48 px в кадре 1080×1920, заголовки ≥ 96 px.
