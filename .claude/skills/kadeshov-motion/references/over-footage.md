# Графика поверх видео (Seedance / свои клипы) и финальные карточки

Правила наложений HyperFrames — `hyperframes/references/overlays.md` и `captions.md`.

## Поверх клипа
- `<video>` таймится сам, без обёртки; звук клипа — `data-has-audio="true"`, иначе `muted`.
- Текст не перекрывает лицо и главное действие: сначала посмотри кадры клипа (`ffmpeg -ss … -frames:v 1`), найди свободную зону.
- Читаемость поверх светлого/пёстрого видео: подложка, градиент снизу или тень, а не обводка.
- Цвет и зерно графики подгоняй под клип; грейд клипа — через `npx hyperframes media-treatment`.
- Видео в Seedance **не генерировать без разрешения пользователя**; работать с присланными клипами.

## Исторические / документальные финальные карточки
- **Факты — только из найденных реальных источников** (энциклопедии, научные статьи, официальные архивы, крупные СМИ). Ищи через веб-поиск; каждую дату, цифру и имя сверяй минимум с двумя источниками.
- Если факт не подтвердился — не пиши его. Лучше меньше текста.
- Список источников (название, ссылка) отдай пользователю вместе с роликом; на экране — по желанию мелким шрифтом.
- Формат карточки: 1–3 строки, ≤ 20 слов, стоит на экране ≥ 3 с, спокойное появление (fade + лёгкий подъём), без суеты.
- Казахские названия и имена пиши в принятом казахском написании; проверь знаки по [kazakh-type.md](kazakh-type.md).
