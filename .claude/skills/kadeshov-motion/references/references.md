# Работа с референсом («сделай как в этом ролике»)

Полный разбор и пересборку видео делает скилл `/reverse-any-video`; перенос стиля на новую тему — `hyperframes/references/look.md` и `/style-sampling`.

## Разбор
1. Кадры: `ffmpeg -i ref.mp4 -vf "fps=2,scale=360:-1,tile=6x6" sheet.png` — контактный лист.
2. Склейки: `ffmpeg -i ref.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null -` — где монтажные стыки.
3. Запиши: темп (средняя длина сцены), шрифты и кегли, палитра, как приходит текст, типы переходов, движение камеры, звук (музыка, SFX на действиях).

## Перенос
- Переноси **приёмы** (ритм, способ подачи текста, тип переходов), а не сам ролик.
- Свои тексты, свои цвета/шрифты в духе оригинала, свои сцены.
- Не копировать один в один: чужих персонажей, логотипы, фирменные стили, музыку.
