# Движение

Базовые правила HyperFrames по easing, титрам, склейкам и паузам — в `hyperframes/references/motion.md`. Здесь — стиль kadeshov поверх них.

## Камера и слои
- Минимум три плана: передний / средний / задний. Скорость параллакса примерно 1.0 / 0.6 / 0.3.
- Никакого линейного зума плоской картинки: разгон и торможение (`power2/power3`, `expo.out` на прилёт).
- Push-in 3–8 % за сцену; резкий punch-in 10–20 % — только на акцент.
- Финальный читаемый кадр может стоять неподвижно.

## Текст как актёр
1. Сначала свёрстай финальную раскладку (кегль, переносы, выключка) и проверь читаемость на 360 px.
2. Потом придумай, как текст в неё приходит: собирается по буквам/словам, ломается, его толкает объект, он отбрасывает тень.
3. Разбивка по буквам: stagger 0.02–0.04 с; по словам: 0.06–0.12 с.
4. Текст не уходит за 80 % title-safe зону.

## Физика объектов
- Вес: тяжёлое разгоняется медленно, лёгкое — быстро.
- Инерция: overshoot 3–8 % и возврат (`back.out(1.4)`), отскок — `bounce.out` только для лёгких предметов.
- Контакт: тень сжимается и темнеет при касании; объекты не висят в воздухе без причины.

## Оптика и плёнка
- Motion blur пропорционально скорости (быстрый пролёт — да, медленный дрейф — нет).
- Глубина резкости на крупных планах: фон размыт сильнее переднего плана.
- Зерно, виньетка, грейд на видео — только через `npx hyperframes media-treatment`, не CSS-фильтры.
- Если ролик кажется перегруженным — убери треть движения, оставь то, что ведёт глаз.
