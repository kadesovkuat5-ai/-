# Qalta — бизнес дәптері

Клиника, стоматология, автосервис (СТО), шиномонтаж, дүкен, сұлулық салоны және басқа бизнеске арналған
телефон программасы (PWA). Телефонға иконка болып орнатылады, интернетсіз де ашылады.

## Не істей алады
- **Бизнес түрін таңдау**: рөлдер мен қызметтер өзі қойылады.
- **Рөлдер, логин-пароль**:
  - Директор / Иесі: бәрін көреді (пайда, есеп, баптау).
  - Администратор: клиенттер, қабылдау, шығыс. Пайданы көрмейді.
  - Стоматолог / Шебер / Сатушы: тек өз жұмысын көреді.
- **Клиент базасы**: телефон немесе аты бойынша іздеу. Бұрын келген адам бірден шығады.
  Әр жаңа клиенттің қайдан келгені жазылады (Instagram, WhatsApp, 2ГИС, сарафан…).
- **Қабылдау**: қызмет, сомасы (калькулятормен: `15000+2500`), төлем түрі, қызметкер. СТО-да көлік те жазылады.
- **Шығыс**: санаттары бар.
- **Айлық есеп**: кіріс, шығыс, салық, міндетті төлемдер, таза пайда, клиенттердің қайдан келгені,
  қызметкерлер бойынша есеп. Оны WhatsApp-пен жіберуге, Excel (CSV) немесе PDF етіп алуға болады.
  Айдың 1–10 күндері еске салады, ал күнтізбеге (.ics) еске салғыш қосуға болады.
- **Сақтық көшірме**: JSON файл түрінде жүктеп алып, кейін қайтаруға болады.

## Маңызды
- 1-нұсқада деректер **тек сол телефонда** сақталады. Сондықтан барлық қызметкер бір телефонды немесе бір
  планшетті қолданады. Бірнеше телефонды ортақ базаға қосу үшін келесі қадамда онлайн база (Supabase) керек.
- Пароль бөгде адамнан қорғайды, бірақ бұл банктік деңгейдегі қорғаныс емес.
- Салық пен төлем мөлшерлері шамамен алынған. Оларды Баптау бөлімінде өзгертуге болады. Ресми декларация үшін бухгалтермен тексер.

## Телефонға орнату
1. GitHub → репозиторий → **Settings → Pages** бөлімін аш. Branch ретінде осы бранчты және `/ (root)` таңда, сосын **Save** бас.
2. Телефонда `https://<username>.github.io/<repo>/qalta/` сілтемесін аш.
3. iPhone: Safari → «Бөлісу» → «На экран Домой». Android: Chrome → ⋮ → «Добавить на главный экран».

Файлдарды өзгерткен соң `sw.js` ішіндегі `VERSION` мәнін ауыстыр. Сонда телефондар жаңа нұсқаны жүктеп алады.
