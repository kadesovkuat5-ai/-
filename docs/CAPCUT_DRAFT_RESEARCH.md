# Can we generate a native, editable CapCut project for iPhone?

**Short answer: not directly on iPhone. Possible only through a computer, unofficially.**

## Қысқаша (қазақша)

- **iPhone-ға тікелей CapCut жобасын жасап беру мүмкін емес.** iPhone-дағы CapCut өз жобаларын қосымшаның
  жабық папкасында сақтайды. Сырттан жоба файлын салатын ресми жол жоқ.
- **Компьютер арқылы болады, бірақ ресми емес:** ноутбукта CapCut Desktop жобасын бағдарлама арқылы жасауға
  болады (оның ішкі файлы `draft_content.json`). Оны CapCut Desktop-та ашып, **CapCut Cloud**-қа жүктеп,
  iPhone-да ашуға болады. Бірақ CapCut жаңарған сайын бұл жол бұзылуы мүмкін.
- **Сондықтан біздің негізгі жол – «CapCut kit»:** бөлек клиптер, бөлек дыбыстар, субтитрлер, толық монтаж
  кестесі және қадам бойынша нұсқаулық. Бұл әрқашан жұмыс істейді.
- **MP4 файлы ешқашан өңделетін жоба емес.** Ол тек дайын көрініс.

## Findings

| Question | Finding | Confidence |
|---|---|---|
| Is there an official CapCut project import or format? | No. There is no published spec or API for project files. | High |
| Can a project file be dropped into CapCut on iPhone? | No supported way. iOS keeps app data sandboxed, and CapCut mobile has no "import project" feature. | High |
| Can CapCut **desktop** drafts be generated by code? | Yes, unofficially. Community tools write `draft_content.json` / `draft_info.json` (pyCapCut, pyJianYingDraft, capcut-cli). | Medium |
| Are desktop drafts encrypted? | The Chinese build (JianYing 6.0+) encrypts drafts. Community notes say CapCut International still uses plain JSON, but the format changes between versions. | Medium |
| Can a desktop project get to iPhone? | Third-party guides say: upload it to CapCut **Cloud space** on desktop, then open it on the phone with the same account. Not officially documented for generated drafts. | Low–medium |
| Can CapCut on iPhone import SRT? | CapCut's own help page says SRT import is desktop/web only. Mobile has **Auto captions** instead. | High |

## What this means for our workflow

1. **Main route (always works):** ReelKit builds a *CapCut kit*:
   - numbered separate clips
   - separate voice, music and SFX files
   - SRT subtitles plus a green-screen subtitle overlay for iPhone (Chroma key)
   - a frame-accurate timeline (`.md`, `.csv`, `.json`)
   - a step-by-step guide for rebuilding the edit in CapCut on iPhone
2. **Optional experimental route (needs the laptop):** convert `timeline.json` into a CapCut Desktop draft
   with a community library, open it in CapCut Desktop, upload it to Cloud space, and open it on iPhone.
   This is not built yet. It would only be worth building after a manual test on the user's CapCut version,
   because any CapCut update can break it.
3. **Never** describe the preview MP4 as an editable project. It is a flat, finished video.
