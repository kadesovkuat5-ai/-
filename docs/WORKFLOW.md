# Жұмыс тәртібі: шикі видеодан → CapCut-қа дейін

Бұл жол **Claude видеоны автоматты түрде талдап, монтаждайды**, ал сіз **iPhone-дағы CapCut-та
қолмен жалғастырасыз**.

```
 Сіз                      Claude (бұлтта)                              Сіз (iPhone)
 ───                      ───────────────                              ────────────
 шикі видеолар  ──►  1. ТАЛДАУ   (сөз, үзіліс, сахна, жарық)
                     2. ЖОСПАР   (қай бөлік, қай ретпен, музыка, эффект)
                     3. ЖИНАУ    (CapCut kit: бөлек файлдар + preview)  ──►  CapCut-та жалғастыру
```

## 1-қадам: Видеоларды жіберу

- Ең оңайы: видеоларды осы чатқа тіркеңіз (егер қосымша рұқсат етсе).
- Болмаса: GitHub-та жобаңызды ашыңыз → `input` папкасы → **Add file → Upload files**
  (браузерден бір файл 25 MB-қа дейін).
- Маған тілді айтыңыз (қазақша `kk`, орысша `ru`) және мақсатты ұзақтықты (мысалы 30 секунд).

## 2-қадам: Claude талдайды (`analyze`)

```
python3 reelkit/reelkit.py analyze input/ --language kk
```
- **Сөз** (Whisper): әр сөздің дәл уақыты, субтитр үшін.
- **Үзілістер**: тыныштық қай жерде, оларды алып тастау үшін.
- **Сахна ауысулары**: кадр қай жерде өзгереді.
- **Жарық пен дыбыс деңгейі**.
- iPhone **HDR** видеосы танылады, түсі бұзылмайды.

## 3-қадам: Claude жоспар жасайды (`plan`)

```
python3 reelkit/reelkit.py plan --target 30 --hook "Қызықты басы!" --music input/music.mp3
```
`work/edit.json` файлы пайда болады. Онда:
- **clips**: әр бөліктің басы мен соңы (түпнұсқа видеодағы секунд), кадр (`fill` = кесу,
  `blur` = бұлдыр фон), zoom, ауысу (`cut` / `fade`)
- **music**: файл, дауысы, сөйлегенде басылуы
- **sfx**: дыбыс эффектілері және олардың уақыты
- **captions → fixes**: Whisper қате жазған сөздерді түзету (мысалы `"кафеи": "кофейни"`)

Автоматты жоспар тек бастама. **Claude оны оқып, жақсартады**: ең жақсы hook-ты бірінші қояды,
артық бөлікті алып тастайды, b-roll-ды дұрыс жерге қояды, мәтіндегі қателерді түзетеді.

## 4-қадам: Claude жинайды (`build`)

```
python3 reelkit/reelkit.py build --name my_reel
```
Нәтиже: `output/my_reel_capcut_kit.zip`

| Папка | Ішінде |
|---|---|
| `1_clips/` | Бөлек клиптер, ретімен нөмірленген. Түпнұсқа кадр мен дыбыс, тек кесілген. HDR сақталады |
| `2_audio/` | Сөйлеу, музыка, дыбыс эффектілері (уақыты файл атында), толық араласқан дыбыс |
| `3_subtitles/` | `subtitles.srt` (синхрондалған), жасыл фондағы субтитр видеосы, мәтін |
| `4_preview/` | Дайын MP4 (мәтінмен және мәтінсіз). **Тек көру үшін, өңделетін жоба емес** |
| `5_timeline/` | Толық монтаж кестесі: `timeline.md` (оқуға), `.csv` (Excel), `.json` (бағдарлама) |
| `START_HERE.md` | iPhone CapCut-та жинау нұсқаулығы, қадам бойынша |

## 5-қадам: Сіз CapCut-та жалғастырасыз

`START_HERE.md` ішіндегі 12 қадамды орындаңыз. Қысқаша:
1. ZIP → **Files** → ашу → клиптерді **Photos**-қа сақтау.
2. CapCut → **New project** → клиптерді ретімен таңдау → **Ratio 9:16**.
3. Кестедегі zoom, ауысулар, музыка, эффектілер.
4. Субтитр: **Auto captions** (оңай) немесе жасыл фонды **Overlay + Chroma key** (біздің стиль).
5. `4_preview` ішіндегі видеомен салыстырып, **Export**.
